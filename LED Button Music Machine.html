Check before wiring

  1. Buttons switch to ground. Set each button pin as an input with the internal pull-up on. It reads LOW when pressed.
  2. LED voltage. Arcade buttons are often 5 V or 12 V with a resistor already inside. If yours are, drop the 220 Ω and feed them from the matching rail instead of 3V3.
  3. LEDs are always on here. To light a button only when it is pressed or a song plays, give each LED its own GPIO through its resistor.
  4. Prox sensor on 3V3. Many IR sensors run on 5 V too, but then their output can be 5 V, which can damage a 3.3 V nRF pin.
  5. Amp on 5V. The amplifier takes the most current, so feed it from +5V, not the board's 3V3 pin.
  6. One shared ground. Supply, board, sensor, SD card and amp grounds must all connect.
